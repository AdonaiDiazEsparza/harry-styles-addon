# The harry styles Addon
This is a little project created for fun and love, since time ago a met a person who likes Harry Styles and an appreciated present from me is create this addon or badge or PCB as you like to call it.

## Components Hardware

| Component          | Name                 |
|--------------------|----------------------|
| MCU                | Ch32v203c8t6         |
| LiPo Charger       | TP4050/TC4050        | 
| USB Conector       | USB-C 16 pin         |
| BATTERY            | LiPo JST connector   |
